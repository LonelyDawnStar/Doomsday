## 4계열 트리
기본: 근접 자동 평타 / E: 4초 평타 강화.
마법공학 → 원거리 마법사 / 전투 마법사 / 기계 소환
기계공학 → 기계 소환 / 탱크 / 드론
주먹 → 공속 / 치명타 / 브루저
체력 → 브루저 / 몸통 박치기 / 극탱
기계 소환·브루저는 두 계열에서 모두 진입할 수 있습니다.
1차: 첫 웨이브 종료. 2차: 캉 격파. 각성: 더 마블스 격파.

## 테크별 외형
룬·마법진, 포신, 소환 장치, 드론 거치대, 건틀릿, 흉갑, 방패형 장갑이 테크에 따라 추가됩니다.
장착 스킨의 색과 금속 재질을 사용하며 태엽은 회전 톱니, 마법 스킨은 룬, 백금은 왕관 장식을 추가합니다.
진화 선택창에서 현재 스킨을 입힌 후보 외형을 확인할 수 있습니다.

## 조작
WASD/방향키 또는 터치 조이스틱 이동. Space 회피. E 강화/전용 스킬. P 일시정지.
기본 근접 공격은 적에게 접근해야 자동 발동합니다.
원거리 마법사와 탱크는 원거리 평타로 변경됩니다.
드론은 근접 평타 적중 후 추가 사격, 기계 소환은 자율 사격입니다.
몸통 박치기는 회피 이동 경로의 적에게 충돌 피해를 줍니다.

## 검증
공유 분기 포함 12개 진화 경로, 기본 근접 사거리, 스킬을 테스트했습니다.
10종 스킨 × 15개 형태(기본 포함) Canvas 렌더링을 실행했습니다.
실제 브라우저 전체 UI·터치와 장기 플레이 밸런스는 미검증입니다.
