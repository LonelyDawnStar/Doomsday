## 성장
첫 챕터 1웨이브 완료 → 과학 / 마법 / 군주 중 1차 선택.
캉 격파 → 같은 계열의 2차 테크 선택.
과학: 중화기(관통 포격) / 기동 슈트(양손 연사·회피 사격).
마법: 파괴 마법(폭발탄·지속 마법진) / 시간·공간(유도탄·잔상·감속장).
군주: 둠봇 지휘관(3기 지원 사격) / 철갑 군주(근거리 산탄·방어·반격).
더 마블스 격파 → 각성: 기본 공격 강화, 해당 테크의 추가 효과.
중화기 관통 3→5, 둠봇 3→4, 시간장 5→7초, 잔상 3→5초, 마법진 3→5초.
적 처치 경험치로 레벨업 및 능력치 포인트 획득.
전투 좌측의 테크/경험치 버튼 → 공격력·연사·이속·체력 투자(각 8단계).
선택 창이 열리면 전투 시간은 정지합니다.

## 전투 템포
챕터당 3웨이브. 각 웨이브는 최소 24초와 적 전원 처치 조건을 모두 충족해야 종료.
챕터별 48 / 57 / 66 / 75 / 84마리. 적 생성 간격 1.35초, 동시 최대 10마리.
추격형, 사격형, 중장갑형 적이 등장합니다.
보스 체력: 쉬헐크 1300 / 캉 2100 / 퓨리 2700 / 더 마블스 각 1250 / 아이언하트 4100.
보스 체력 50% 이하: 이동 속도 상승, 공격 간격 감소, 2회 공격마다 단발 추가 탄막(더 마블스 제외)과 진입 장판.
더 마블스는 세 명 전원 격파해야 다음 챕터로 진행.

## 조작
WASD/방향키 이동, Space 회피, E 전용 파동, P 일시정지. 자동 공격.
터치는 왼쪽 조이스틱과 하단 버튼 사용.

## 검증
6개 테크 경로, 웨이브 최소 시간, 5챕터 전환, 보스 2페이즈, 3인 격파 조건,
각성, 경험치·능력치 지출, 전용 스킬을 자동 로직 테스트했습니다.
실제 Canvas 백엔드로 6개 테크의 렌더링을 실행했습니다.
실제 브라우저 UI·터치 및 장시간 플레이 밸런스는 미검증입니다.

비공식 팬 패러디. 첨부 사진은 참고만 했으며 캐릭터는 Canvas 전신 벡터로 그립니다.

## 0.4.1 보스 난이도 완화
보스 체력 약 39~42% 감소, 보스 탄속 15% 감소. 보스 탄환 피해 13→10, 접촉 20→15, 장판 24→18.
일반 보스 공격 간격 2.2초 / 2페이즈 1.7초. 2페이즈 이동 배율 1.12.
더 마블스 공격 간격 3.5 / 4.1 / 4.6초, 첫 공격 시점 분산, 추가 탄막 제거.
보스전 진입 시 체력 25 회복 및 2초 무적. 쉬헐크 강타 예고 1.1초.
테크 트리와 잡몹 웨이브 조건 유지. 실제 플레이 난이도는 추가 확인이 필요합니다.

## 0.5 타이틀 · 스킨 의장고
앤틱 녹색/황동 타이틀, 회전 톱니바퀴 Canvas 애니메이션. 모션 줄이기 설정 지원.
무료 스킨 뽑기, 10종 보관함, 장착, 로컬 저장. 유료 재화나 결제 없음.
커먼 55% / 레어 30% / 에픽 12% / 레전더리 3%. 등급 내 균등 확률.
커먼: 체력 +4
레어: 체력 +6, 공격 +1.5%
에픽: 체력 +8, 공격 +2.5%, 이동 +1%
레전더리: 체력 +10, 공격 +3.5%, 이동 +1.5%
장착한 한 벌만 다음 게임부터 적용. 중복 스킨은 버프가 중첩되지 않습니다.
저장은 해당 브라우저/주소에 한정되며 다른 기기로 동기화되지 않습니다.
확률 경계, 미보유 장착 차단, 저장, 중복 처리, 버프 비중첩, 스킨 및 톱니 렌더링을 테스트했습니다.
전체 브라우저 UI/실기기 터치 검증은 미완료입니다.
