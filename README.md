# DOOM / AFTER THE END — 0.3

전체 실행본 / GitHub + Vercel 정적 배포용

## 실행과 배포
- 로컬에서는 index.html을 브라우저로 여세요.
- GitHub 저장소 최상위에 index.html과 vercel.json을 올리세요.
- 기존 저장소라면 같은 이름의 파일을 교체하세요. 부분 패치가 아닌 전체 실행본입니다.
- Vercel에서 해당 저장소를 Import하고 Framework Preset을 Other로 선택하세요.
- Root Directory는 저장소 루트로 유지하고 Deploy하세요.
- 빌드 명령, 설치 명령, 환경 변수, 외부 이미지 파일은 필요하지 않습니다.

## 새 디자인
첨부 사진은 캐릭터의 의상·색상·특징을 파악하는 참고로만 사용했습니다.
원본 사진, 잘라낸 초상, 포스터, Base64 이미지 데이터는 포함하지 않습니다.
9명 모두 Canvas의 경로와 관절로 새로 그린 전신 캐릭터입니다.
걷기, 공격 자세, 망토 움직임, 비행 효과, 피격 반응을 적용했습니다.
타이틀과 전투 HUD도 같은 캐릭터 렌더러를 사용합니다.

## 등장 순서
플레이어: 닥터 둠
1. 쉬헐크 — 강타와 돌진
2. 정복자 캉 — 순간이동과 시간 탄막
3. 닉 퓨리와 스크럴 군단 — 사격과 소환
4. 캡틴 마블·모니카·미즈 마블 — 세 명 동시 전투, 각자 체력, 전원 격파 필요
5. 아이언하트 — 비행 재배치, 리펄서와 폭격

## 조작
WASD/방향키: 이동. Space: 회피. E: 둠 파동. P: 일시정지.
태블릿은 왼쪽 조이스틱과 하단 버튼을 사용하세요. 공격은 자동입니다.
보스 격파 후 공격력·체력·추가 탄환 중 하나를 강화합니다.
